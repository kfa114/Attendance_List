# 서명란 본인 이름 안내 및 저장 서명 미리보기

2026-10-22. 아직 운영 배포 전인 변경입니다.

- ‘이름을 써주세요’ 대신 선택한 본인의 이름을 서명란 가운데 연한 글씨로 표시합니다. 글자 크기는 이름 길이와 캔버스 크기를 측정해 너비 약 70%에 맞추며, 높이도 70%를 넘지 않습니다. 안내는 DOM 요소이므로 저장된 서명 이미지에 포함되지 않습니다.
- 저장된 서명 불러오기 → 캔버스에 이미지 표시 → 사용자가 확인 → ‘서명 완료’ 순서로 변경했습니다. 불러오기 중에는 입력/제출 버튼을 잠그고, 완료 후에는 확인 안내와 제출 버튼을 표시합니다.
- `savedSignaturePreview`는 기존 서명과 동일한 프로그램·참여자·이전 날짜·원본 ID·QR 범위·마감 검증 후 해당 이미지 하나만 반환합니다. 출석 레코드나 새 파일을 저장하지 않습니다.
- 손대지 않은 저장 서명을 최종 제출하면 기존 `reuseSignature`로 원본을 재참조합니다. 추가 획을 그렸으면 현재 캔버스 이미지를 직접 서명으로 저장합니다.
- 화면 크기를 바꿀 때 불러온 이미지와 추가 획을 복원합니다. ‘다시 쓰기’는 이미지와 획을 모두 지우고 본인 이름 안내를 다시 표시합니다.
- 취소하거나 창을 닫으면 미리보기만으로 출석이 반영되지 않습니다. 최종 제출 시 원본이 취소되었거나 마감된 경우에는 기존 서버 검증으로 차단됩니다.

## 검증

- `npm run check`: 일반 55개 + SQLite 6개 = 61개, 빌드 통과.
- 새 테스트: 미리보기 전후 출석 레코드 수 동일, 최종 제출 후에만 1건 추가, QR 시간·다른 사람·원본 취소·마감 차단.
- 독립된 가상 명단 서버에서 360px 휴대폰 UI 확인: 캔버스 318px, 안내 텍스트 222.6px(70%) 확인.
- 저장 서명을 불러온 후에도 서명 모달 유지, 제출 활성화, 당일 출석 레코드 0건 확인. 768px 크기로 바꿔도 이미지가 유지되는 것을 화면으로 확인했습니다.
- ‘서명 완료’ 후 완료 화면과 당일 출석 1건 생성 확인. 브라우저 오류 없음.
- 증빙은 Git에서 제외된 `docs/screenshots/signature-name-guide.png`, `signature-loaded-preview.png`, `signature-preview-resized.png`입니다.


## 가이드 유지·연락 관리 높이 후속 수정

- 이름 가이드를 채도 없는 연한 회색 `#e5e5e5`로 변경하고 서명 중·불러온 서명 위에서도 계속 표시합니다. multiply 합성으로 검은 서명 획이 흐려지지 않게 처리합니다. 가이드는 계속 별도 DOM 요소이므로 저장 이미지에 포함되지 않습니다.
- 연락 관리 담당자 input과 결과 select에 동일한 44px 높이와 세로 패딩을 적용했습니다.
- 빌드 통과. 360px 화면에서 캔버스에 실제 획을 그린 후 가이드 유지 확인. PC와 360px 연락 관리 화면의 네 행 모두 input/select 높이가 각각 44px임을 측정했습니다.
