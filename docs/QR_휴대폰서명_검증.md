# 중복 번호 선택 · 교육일 달력 · QR 휴대폰 서명

2026-10-20 변경. 운영 배포 전 로컬 Cloudflare Worker/SQLite 검증 결과입니다.

## 사용 방법

1. 교육생 조회: 휴대폰 뒷자리 4개 입력. 중복이면 해당 번호의 이름과 명단 순번이 표시됩니다. 본인을 선택하고 ‘내 출결 조회’를 누릅니다. 이름까지 같아도 순번으로 구분합니다.
2. 명단 생성/설정: 달력에서 날짜를 클릭하면 즉시 교육일에 추가됩니다. 이미 추가한 날짜를 다시 눌러도 중복되지 않습니다. 하단 날짜 칩에서 삭제합니다. 기록이 있는 날짜는 서버가 삭제를 차단합니다.
3. 태블릿 탭: 오늘 교육일과 서명 시간을 선택하고 ‘휴대폰 서명 QR 생성’을 누릅니다. 참여자는 QR로 접속해 큰 이름 버튼을 선택하고 서명한 뒤 ‘서명 완료’를 누릅니다. 완료 안내 후 창을 닫습니다.
4. 스마트폰이 없는 참여자는 같은 태블릿 탭의 직접 서명을 이용합니다. 서명한 사람은 태블릿 직접 서명 목록에서 숨기고, 휴대폰에서는 ‘서명 완료’로 표시합니다.

## 권한과 기존 기록

- QR 생성 권한은 관리자 및 해당 프로그램의 태블릿 세션입니다.
- QR은 별도 `signing` 세션입니다. 관리자/태블릿 토큰을 QR에 넣지 않습니다.
- 휴대폰에는 제목, 지정 날짜·시간, 이름·순번·완료 여부만 전달합니다. 연락처, 비고, 결석 신고, 강사 판단, 서명 이미지, 출력 기능은 전달하지 않습니다.
- QR은 특정 프로그램·날짜·시간에 묶입니다. 변경한 날짜나 시간으로 요청해도 서버에서 거절합니다.
- 유효기간은 최대 6시간이며 발급자의 세션 만료를 넘지 않습니다. 오전 13시, 오후/단일 서명 18시 마감도 별도로 적용합니다. 날짜·시간을 바꾸면 QR 화면을 초기화해 새로 생성하도록 합니다.
- 보관/휴지통/만료/서명 방식 변경 시 접근 또는 서명을 서버에서 차단합니다.
- QR을 가진 사람은 이름을 선택할 수 있는 현장 출석 방식입니다. 현장 참여자에게만 QR을 표시합니다.
- 기존 명단·서명 기록의 구조를 바꾸거나 삭제하지 않습니다. 기존 SQLite 세션 payload가 추가 필드를 그대로 저장하므로 DB 마이그레이션은 필요하지 않습니다.

## 유지보수 위치

- `src/components/EducationCalendar.tsx`: 즉시 추가 달력.
- `src/components/SigningQr.tsx`: QR 생성·표시. 오픈소스 qrcode로 기기 안에서 생성하며 외부 QR 생성 서버를 사용하지 않습니다.
- `src/features/MobileSigning.tsx`: 큰 이름 목록·검색·서명·완료.
- `src/features/Student.tsx`: 중복 번호 후보 선택.
- `server/service.ts`: 후보 ID 검증, QR 발급, 최소 명단 반환, 서명 범위 검증.
- `src/components/SignatureDialog.tsx`: 태블릿/휴대폰 공통 서명 입력.

## 검증

- `npm run check`: 일반 46개 + SQLite 5개 = 51개 통과, TypeScript/Vite 빌드 통과.
- `node scripts/test-cloudflare.mjs`: 실제 로컬 Worker에서 QR 발급, 제한된 명단, 범위 밖 요청 차단, 동시 서명 두 건 중 한 건만 저장, PDF 스냅샷, 보관/휴지통/복원 확인.
- 브라우저: 달력 날짜 클릭 → 즉시 선택/날짜 칩, 가상 명단 생성, 같은 뒷자리 1234의 두 사람 중 선택 → 선택한 사람 출결만 조회 확인.
- 브라우저: QR 생성 → QR의 링크로 새 탭 접속 → 이름 선택 → 캔버스에 실제 획 입력 → 저장 완료 → 관리자 현황 1명 완료/태블릿 미서명 목록 제외 확인.
- 반응형: 360px 이름 32px·가로 넘침 없음, 서명 모달·저장 완료 화면 확인. 1024px QR/안내 두 열 배치·가로 넘침 없음 확인.
- 실제 휴대폰 카메라 스캔과 여러 실물 기기 동시 사용은 현장 검증 대상입니다. 브라우저에서는 QR이 담은 링크로 접속해 저장까지 검증했습니다.
- 증빙은 Git 제외된 `docs/screenshots/qr-tablet.png`, `qr-mobile-list.png`, `qr-mobile-complete.png`, `duplicate-name-choice.png`에 저장했습니다. 테스트 명단은 가상 정보이며 로컬 SQLite에만 있습니다.
