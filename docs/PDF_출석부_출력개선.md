# PDF 출석부 출력 개선

2026-10-20. 기존 22mm 이상의 행으로 30명이 3페이지로 나뉘던 구성을 참고 이미지의 간결한 표 형식으로 변경했습니다.

- A4 세로, 좌우 14mm, 가운데 제목과 교육일, 회색 머리글, 검정 표 선, 페이지 하단 쪽수.
- 기본 서명: 순번 / 이름 / 서명 / 비고.
- 오전·오후: 순번 / 이름 / 오전 서명 / 오후 서명 / 비고.
- 표준 행 높이는 최대 8mm. 제목이 길면 높이를 조정해 일반적인 30명 명단을 한 페이지에 배치합니다. 31명부터 다음 페이지에 제목·머리글을 반복합니다.
- 이름·비고가 여러 줄이면 잘라내지 않고 행을 늘려 필요한 만큼 페이지를 추가합니다.
- 실제 서명만 서명 칸에 표시합니다. ‘강사 판단 대기’ 등 미서명 상태 문구는 서명 칸에 인쇄하지 않습니다. 강사가 확정한 출석·결석은 비고에 표시하며, 오전·오후 판단은 구분합니다.
- 새 출력 버전은 생성 시점의 참여자 비고도 저장합니다. 기존 출력 스냅샷은 원본 기록을 유지하므로 당시 저장되지 않은 비고를 나중에 덧붙이지 않습니다.
- 브라우저에서 기존 PNG 서명의 흰색/투명 여백을 잘라 표에 배치합니다. 저장된 원본 서명 이미지는 변경하지 않습니다. 기존 출력 스냅샷도 새 다운로드 레이아웃으로 표시됩니다.

## 검증

- 전체 일반 테스트 50개 + SQLite 테스트 5개, TypeScript/Vite 빌드 통과.
- 기본·오전오후 각각 30명 1페이지, 31명 2페이지, 60명 2페이지, 61명 3페이지 확인.
- 100자 제목의 일반 30명 명단도 1페이지 확인.
- 서명 이미지의 흰 여백·투명 픽셀·잉크·가장자리 패딩 계산 확인.
- 기본·오전오후 30명 PDF를 생성하고 PNG로 렌더링하여 제목·표·서명·비고·30번째 행·쪽수 확인.
- 실제 로컬 Cloudflare API에서 가상 30명 명단과 서명·출력 스냅샷 생성 → 웹앱 다운로드 버튼으로 PDF 다운로드 → `pdfinfo`에서 A4 1페이지 확인 → PNG 렌더링 검토 완료.

예시는 가상 명단이며 `output/pdf/`에 보관합니다. 생성물·테스트 데이터는 Git에 포함하지 않습니다.
