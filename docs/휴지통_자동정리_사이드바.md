# 달력 너비 · 휴지통 7일 자동 삭제 · 사이드바 프로그램 목록

2026-10-22 로컬 구현/검증. 아직 GitHub 푸시 및 운영 배포 전입니다.

## 사용 화면

- 새 명단/설정 달력은 프로그램명 입력란과 오전·오후 설정 카드의 너비와 같습니다. PC에서 세 요소 640px, 360px 휴대폰에서 세 요소 320px로 측정했습니다.
- 사이드바 ‘명단 관리’는 접이식 버튼입니다. 누르면 홈으로 이동하며 운영 중 프로그램 목록을 펼치거나 접습니다. 이름순으로 표시하고 선택하면 해당 명단으로 이동합니다. 보관·휴지통은 제외하며 빈 목록 안내와 현재 프로그램 강조를 지원합니다.
- 프로그램 설정에서 이름/상태를 바꾸면 사이드바 목록도 갱신합니다.
- 삭제 확인 화면과 휴지통 화면에 7일 후 영구 삭제를 안내하고, 카드에 한국 시간의 삭제 예정일을 표시합니다.

## 보관 기한과 정리 범위

- `Program.deletedAt`에 휴지통 이동 시각을 기록하며 보관 기한은 정확히 168시간입니다. 반복 삭제 요청은 기한을 늘리지 않습니다. 기한 전에 복원하면 삭제 시각을 제거하며 다시 삭제할 때 새 기한을 시작합니다.
- 기존 휴지통은 기존 `updatedAt`을 삭제 시각으로 사용합니다. 기존 날짜가 없거나 유효하지 않으면 첫 정리 실행 시점부터 7일간 보관합니다. 이미 7일이 지난 기존 항목은 다음 정리에서 영구 삭제됩니다.
- 기한이 되면 목록·복원 대상에서 제외합니다. 실제 저장소 정리는 Cloudflare Cron `0 * * * *`(매시간)과 API 요청 시 실행하므로 무접속 상태에서도 정리되며, 요청이 없으면 물리 삭제가 기한 이후 최대 약 한 시간 늦을 수 있습니다.
- 해당 프로그램의 참여자·서명(취소/재사용 포함)·결석 신고·강사 판단·연락 기록·작업 이력·출력 버전과 연결된 비공개 이미지/스냅샷 파일, 프로그램 전용 세션 및 학생 조회 제한 키를 삭제합니다.
- SQLite 단일 트랜잭션으로 처리하므로 중간에 실패하면 파일과 레코드를 모두 롤백합니다. 재실행해도 안전하며 다른 프로그램과 연결된 파일은 보호합니다. 보관/운영 프로그램 및 전역 관리자 세션은 유지합니다.
- 공개 영구 삭제 API는 만들지 않았습니다. 예약 핸들러는 고정 워크스페이스 Durable Object의 비공개 정리 경로를 호출합니다.
- 별도 DB/스토리지 마이그레이션 없이 선택 필드만 추가합니다. 기존 namespace/객체 이름을 변경하지 않습니다. 물리 삭제 스케줄은 Cloudflare 운영 환경에 적용되며 기존 Node/GAS 미리보기에는 영구 정리 스케줄을 추가하지 않습니다.

## 코드 위치

- `src/domain/trash.ts`: 보관 기간/기한 공통 계산.
- `server/service.ts`: 삭제 시각 기록, 복원과 기한 검증, 만료 목록 제외.
- `server/cloudflare/trash.ts`: 영구 정리 트랜잭션.
- `server/cloudflare/index.ts`, `wrangler.jsonc`: 예약 실행과 API 시 정리.
- `src/App.tsx`: 접이식 목록, 삭제 안내/예정일.
- `src/styles.css`: 달력 너비와 사이드바 목록.

## 검증

- `npm run check`: 일반 56개 + Cloudflare/SQLite 10개 = 66개 통과. TypeScript/Vite 빌드 통과.
- 7일 직전 보존/정확한 기한 만료, 복원·재삭제, 반복 삭제의 기한 유지, 기존 날짜 처리, 이미지/PDF/모든 연결 레코드·세션 정리, 다른 프로그램 보호, 실패 시 롤백/재시도 검증.
- Cloudflare 로컬 예약 작업 API에 `cron: "0 * * * *"`로 실행한 결과 `success: true`, `outcome: "ok"` 확인. `/__scheduled` 주소는 정적 자산 SPA 응답이므로 성공 증거로 사용하지 않았습니다.
- 브라우저에서 사이드바 펼침/접힘, 운영 항목만 표시, 선택한 프로그램 URL로 이동 확인. 휴지통 삭제 예정일과 안내 확인.
- UI와 스케줄 테스트는 가상 로컬 데이터만 사용했습니다. 운영 저장소는 변경하지 않았습니다.
